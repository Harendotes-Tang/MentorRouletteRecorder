# 协议档案：繁中服

服务区服身份为 `TC`，目录为 `tc`；它独立于 `CN`、`GLOBAL` 以及界面语言 `zh-TW`。

当前只有 `tc-unsupported.json`：状态 `UNSUPPORTED`、零消息、无指导者轮盘编号、无校准模板。正式自动记录不可用。显式选择 TC 可进行满足采集与解码前提的候选观察；观察摘要不证明协议字段或通关语义，不会自动成为 VERIFIED。

首份正式档案必须有独立繁中服客户端版本、报文结构和语义的可追溯证据，并通过本项目验证。不得继承国服模板、通关/开场识别或使用界面繁体翻译证明已实装。安装路径只有玩家公开报告的启动器默认目录 `C:\Program Files\USERJOY GAMES\FINAL FANTASY XIV TC`（启动器为 `FfxivLauncherTC.exe`），据此识别 `USERJOY GAMES` 与 `FINAL FANTASY XIV TC` 两个关键字；其他目录保持未知并由玩家显式选择区服。该判定只影响区服身份，不使任何协议档案可用。

证据与档案格式见 [protocol-profile-format.md](../../docs/protocol-profile-format.md)；繁中服测试者的采证流程见 [traditional-chinese-server-testing.md](../../docs/traditional-chinese-server-testing.md)，维护者的真机验收见 [live-validation-guide.md](../../docs/live-validation-guide.md)。不要提交原始报文、角色名或其他玩家信息。
